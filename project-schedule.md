## 3. Critical Dependencies

- Development completion is required before full integration testing.
- Integration environment and interfaces must be ready before SIT.
- Business stakeholder availability is required for UAT.
- UAT sign-off is required before production deployment.
- Production readiness and rollback approval are required before go-live.

## 4. Schedule Management Approach

The project manager will review milestone progress weekly, track dependencies with workstream leads, and document schedule variances.

Any milestone delay that may affect the go-live date will be escalated through project governance.

Changes to the approved baseline schedule will be documented and reviewed with the project sponsor.
