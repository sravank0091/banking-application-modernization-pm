# RACI Matrix – Banking Application Modernization

## 1. Project Overview

**Project Name:** Banking Application Modernization
**Project Manager:** IT Project Manager
**Status:** Simulated Case Study

## 2. Purpose

The RACI matrix defines roles and responsibilities for key project activities.

* **R – Responsible:** Performs the work.
* **A – Accountable:** Owns the outcome and provides final approval.
* **C – Consulted:** Provides input or expertise.
* **I – Informed:** Receives project updates.

Each activity should have one clearly designated Accountable role.

## 5. Governance and Communication

* The Project Manager coordinates project activities, tracks milestones, and manages escalations.
* The Business Owner approves business requirements and provides final business acceptance.
* The Technical Lead coordinates technical delivery and integration readiness.
* Development and QA teams collaborate to resolve defects and meet acceptance criteria.
* Infrastructure and Security Leads confirm operational readiness and security compliance.

## 6. Review and Change Control

The RACI matrix will be reviewed during project kickoff and whenever project roles or responsibilities change.

Changes to ownership must be communicated to impacted stakeholders and reflected in the project documentation.
