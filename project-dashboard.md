## 5. Project Manager's Focus

- Monitor application and API integration dependencies.
- Track open risks, issues, and mitigation owners.
- Coordinate development, QA, business, and operations teams.
- Escalate schedule or scope changes through governance.
- Confirm testing exit criteria and production readiness.
